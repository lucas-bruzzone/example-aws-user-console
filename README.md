# AWS User Console

Este repositório contém um exemplo simples para criar um usuário administrador na AWS com acesso ao Console de Gerenciamento. O projeto utiliza AWS SDK para automatizar a criação do usuário e a atribuição das permissões necessárias.

## Como usar

1. Clone o repositório:
    ```bash
    git clone https://github.com/seu-usuario/example-aws-user-console.git
    ```
2. Configure suas credenciais AWS.
3. Execute o script conforme as instruções do projeto.

## Funcionalidade

- Criação de um usuário administrador com acesso ao Console AWS

## Requisitos

- AWS CLI ou AWS SDK configurado
- Conta AWS e credenciais configuradas
